## 🙋 About

This is my **personal portfolio website** built from scratch using pure HTML, CSS, and JavaScript — no frameworks, no bloat. It showcases who I am, the projects I've built, my technical skills, and how to get in touch with me.

I built this to have a professional online presence and as a project in itself to demonstrate my frontend development skills.

## 🏁 Getting Started

### Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/Ak5h4tjain/my-portfolio.git

# 2. Navigate into the folder
cd my-portfolio

# 3. Open in browser
open index.html
```

> No installations or build steps needed. Just open `index.html` in any browser!
